# Avainpelaaja OS UI modules

Tämä kansio sisältää käyttöliittymän modulaarisen laajennuskerroksen. Nykyinen tuotantokäyttöliittymä on edelleen juurihakemiston `index.html`, jotta nykyinen DEMO/TYÖ-toiminnallisuus säilyy muuttumattomana.

Uudet moduulit eivät sisällä palvelimen salaisuuksia eivätkä ohita serverin käyttöoikeustarkistuksia.
